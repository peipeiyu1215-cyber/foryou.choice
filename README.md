# 選擇｜全螢幕彈力球互動動畫

整個視窗是球的容器。改變角度，讓手寫字的點點隨重力方向落下、彈跳並碰撞合併。轉到 90° 時合成大球。轉到 180° 時，小球彈回筆畫，拼成「你就該完成我的夢想」。轉完一圈會回到「我們都決定好了」。

## 開啟與操作

- 直接在瀏覽器開啟 `index.html`，或按「播放預覽」觀看完整一圈。
- 拖曳畫面、操作角度滑桿，或在動畫畫面取得鍵盤焦點時按左右方向鍵。
- 使用具備動作感應的手機或平板時，可按「啟用陀螺儀」。瀏覽器可能要求授權，並限制此功能在 HTTPS 網頁上使用。

## GitHub Pages

把此資料夾內的 `index.html`、`README.md` 和 `.nojekyll` 放到 GitHub 儲存庫的根目錄，再將 GitHub Pages 的發佈來源設為該分支的根目錄。

動畫程式與樣式都包含在 `index.html` 裡。楷體使用裝置已安裝的字型，字形可能因裝置而異。
